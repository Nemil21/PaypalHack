# PayPal AI Hackathon — Team Context Pack

> Compiled 2026-11-09 from the Devpost hackathon site, PayPal developer docs, and sponsor pages.
> **Submission deadline: Thursday, Nov 12, 2026 @ 12:00 pm PST (3:00 pm EST).** That is ~3 days from compile date.

## TL;DR (read this first)

- **What:** Global, online, public hackathon by PayPal (run by Devpost). Theme: *"Build what's next with PayPal and AI."*
- **No tracks, no problem statements.** Build anything (agent, app, automation, payment experience, business tool, social product…).
- **The one hard requirement:** the project must **meaningfully use BOTH PayPal (sandbox is fine) AND AI**.
- **Prizes:** $67,500 cash + $2,250 Render credits (= "$69,750 total"). 1st place $12,000. A project can win max **1 Grand OR 1 Honorable Mention, plus 1 Sponsor prize**.
- **Must submit (all required):**
  1. Text description of features/functionality
  2. **Functional demo** — hosted URL *or* complete run instructions in the repo (mockups/static prototypes = fail)
  3. List of AI tools/models used and how
  4. **Public repo** (GitHub/GitLab/Bitbucket) with all code + README + **open-source license visible in the About section**
  5. **Public YouTube demo video < 3 min**, showing it working on the target device, no unlicensed music/trademarks
- **Judging:** Stage 1 pass/fail (fits theme + uses PayPal & AI + all requirements met). Stage 2: five **equally weighted** criteria scored 1–5 — Technological Implementation, Design, Potential Impact, Innovation/Idea, Presentation. **Judges are not required to run your project — the video carries a lot of weight.**
- **After deadline:** submissions lock. Do **not** edit repo/video/linked materials until after winners (Dec 21). Keep demo, test creds, trials/credits alive until then.
