## About the challenge (official text, condensed)

> PayPal already moves money for millions of people and businesses, every day, all over the world. This hackathon is us opening that platform up and asking what happens when you put AI behind the wheel. New agents, new ways to pay and get paid, tools nobody's built yet.

- Invites developers, designers, founders, students, builders.
- **No prescribed problem statements and no tracks.** Build an agent, an app, an automation, a new payment experience, a business tool, a social product, or something else.
- **The only fundamental requirement: your project must meaningfully use both PayPal and AI.**

### "Why join" bullets
- Build something ambitious with PayPal + AI
- Explore how people, businesses, and AI agents interact with money
- Win part of $69,750 total prizes
- Get in front of PayPal judges / community
- Learn PayPal APIs, AI tools, agents, automations
- Solo or team; new project or meaningfully advance an existing one

### Get started (official)
1. Get a PayPal Developer account — https://developer.paypal.com (5 min)
2. Review example projects on the Resources page and brainstorm (30 min)

## Requirements

### What to build
Build or update an application that integrates the **PayPal developer platform (using the free sandbox)** along with an **AI tool, model, or platform of your choice**. Includes all PayPal services: Venmo, Braintree, Xoom, Honey, Zettle, Paidy, Hyperwallet, Simility, Swift Financial, etc.

Optional sponsor tools: AG Grid, APIMatic, Astropods, Bryntum, Channel3, Elastic, KERNEL, Postman, Render, Zapier (details in doc 08). Using them is **not required** — "Any AI tool works, as long as PayPal integration is central to the project."

Your project should:
- Meaningfully integrate ≥1 PayPal technology, API, SDK, product, or developer capability
- Meaningfully incorporate AI into the experience or functionality
- Demonstrate a working prototype or proof of concept
- Be documented enough for judges to understand and evaluate it
- Comply with the Official Rules

New or existing projects allowed — existing ones must show **meaningful/significant progress during the submission period** (and you should explain what was updated).

### What to submit
- **Project** built with the required tools
- **Text description** — features and functionality
- **Functional demo** — judges must be able to run or interact with a working build:
  - clear, complete setup + run instructions in the repo, **or**
  - a hosted demo URL
  - *A design mockup, static prototype, or non-functional demo does NOT meet this requirement.*
- **Tools** — identify which AI models/services were used and explain how
- **Public code repo** on GitHub, GitLab, or Bitbucket — all source, assets, instructions; public and open source with a **license file visible at the top of the repo (About section)**
- **Demo video** — under 3 minutes (judges needn't watch past 3:00); shows project functioning on its target device; **public on YouTube**; link on the form; no third-party trademarks or copyrighted music/material without permission
